# Support

Thanks for using LoTaR.

## Questions / Help

Start with the docs:

- Docs index: [docs/README.md](docs/README.md)
- Help index: [docs/help/index.md](docs/help/index.md)
- Error model and common failures: [docs/help/errors.md](docs/help/errors.md)
- Web server + API reference: [docs/help/serve.md](docs/help/serve.md)

If you're still stuck, ask in [Discussions Q&A](https://github.com/localtaskrepo/lotar/discussions/categories/q-a). Ideas and things you built with LoTaR are welcome in [Discussions](https://github.com/localtaskrepo/lotar/discussions) too.

## Bug Reports

Please open a [bug report](https://github.com/localtaskrepo/lotar/issues/new?template=bug_report.yml) and include:

- What you expected vs what happened
- Repro steps (ideally in a fresh temp repo)
- Output of `lotar --version`
- OS + shell (and Docker version if applicable)
- Any relevant logs (`--verbose` helps)

## Feature Requests

Open a [feature request](https://github.com/localtaskrepo/lotar/issues/new?template=feature_request.yml) describing:

- The workflow you’re trying to improve
- Why LoTaR’s current behavior isn’t enough
- Any constraints (repo scale, monorepo, CI usage)

## Security

Please don't open public issues for security-sensitive reports. See [SECURITY.md](SECURITY.md) for how to report them privately.
